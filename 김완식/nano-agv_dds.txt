배경
모드 명령(/agv_mode)을 1번만 쏘면 AGV가 그 순간 놓칠 수 있어, 확실히 전달될 때까지 fsm이 반복 발행하고 AGV가 수신 확인(ack)을 보내는 구조로 변경합니다.
동작 흐름

모드가 바뀌면 fsm이 /agv_mode를 0.5초마다 반복 발행
AGV가 /agv_mode를 받으면 → 받은 숫자를 그대로 /AGV_mode_ack로 회신 (받을 때마다 1번)
fsm이 ack를 받고 보낸 값과 일치하면 → 반복 발행 중단
(안전장치) 일정 횟수 동안 ack가 없으면 fsm이 발행 멈추고 경고 로그

AGV가 구현할 것

새 토픽 발행: /AGV_mode_ack (std_msgs/Int32)
로직: /agv_mode(Int32)를 수신하면, 받은 그 숫자를 /AGV_mode_ack로 그대로 회신

예: /agv_mode로 10을 받으면 → /AGV_mode_ack에 10 발행
받을 때마다 회신하면 됨 (별도 카운트 불필요, fsm이 알아서 멈춤)

## /target_cmd 인터페이스
토픽: /target_cmd
타입: geometry_msgs/Twist
데이터: linear.x (전후 m/s), angular.z (회전 rad/s)



라디안 각도로 확정. 각도 부호 규칙을 정합니다 (코드에 반영):

타겟이 화면 오른쪽에 있으면 → 각도 음수 (AGV가 우회전 = CW = angular.z 음수와 일치)
타겟이 화면 왼쪽에 있으면 → 각도 양수 (좌회전)

이러면 AGV 엔지니어가 받은 각도 부호를 그대로 angular.z 방향으로 쓸 수 있습니다.
전체 코드를 드립니다. 핵심 변경:

토픽 /target_cmd, 타입 Twist
linear.x = 거리(m), angular.z = 각도(rad)
속도 계산(KP, MAX) 제거 — 거리·각도만 측정해서 발행
타겟 소실 시 회전 탐색 로직은 ws님이 판단해야 하므로 유지하되, 발행은 거리·각도 의미로 정리

먼저 각도 계산 방식 확인 — D435 RGB 수평 FOV는 약 **69°**입니다. 픽셀 cx_err를 각도로 환산:
angle_rad = (cx_err / 640) * radians(69)
화면 가로 640px 전체가 69°에 대응한다고 보고 환산합니다.

## /search_cmd 인터페이스

**토픽:** `/search_cmd`
**타입:** `std_msgs/String`
**데이터:** `"left"` 또는 `"right"`, "find"

---

**용도 — 타겟(사람) 소실 시 탐색 회전 방향**

카메라 노드(follow_node)가 추적하던 사람을 놓쳤을 때, 마지막으로 사람이 사라진 방향을 `/search_cmd`로 발행합니다. AGV는 그 방향으로 **제자리 회전**하며 사람을 다시 찾습니다.

**방향 규칙:**
- `"left"` → 사람이 화면 왼쪽으로 사라짐 → AGV 좌회전(CCW)
- `"right"` → 사람이 화면 오른쪽으로 사라짐 → AGV 우회전(CW)
- "find" -> 사람찾으면 10번보냄 -> AGV 정지

(target_cmd의 각도 부호 규칙과 동일: 왼쪽=좌회전, 오른쪽=우회전)

---

**발행 동작:**
- **사람 추적 중(FOLLOWING):** `/search_cmd` 발행 안 함. `/target_cmd`만 발행.
- **사람 소실:** `/search_cmd`에 `"left"` 또는 `"right"`, find 약 10Hz로 계속 발행. (이때 `/target_cmd`는 발행 안 함)
- **사람 재발견:** `/search_cmd` 발행 중단. `/target_cmd`(거리·각도) 재개.

---

**AGV 엔지니어 쪽 처리 요청 사항 (중요):**

1. `/search_cmd`로 `"left"`/`"right"` 받으면 해당 방향으로 제자리 회전(angular.z만, linear.x=0).

2. **watchdog 필수** — `/search_cmd`가 일정 시간(예: 0.3~0.5초) 동안 안 오면 회전 정지. 카메라가 사람을 다시 찾으면 발행을 멈추는데, AGV가 이걸 "정지 신호"로 해석하려면 타임아웃이 필요함. 이게 없으면 사람을 찾아도 AGV가 계속 회전함.

3. 회전 속도는 AGV 쪽에서 설정 (좁은 공간이면 천천히 권장).

---

**전체 인터페이스 요약 (target_cmd + search_cmd):**

| 토픽 | 타입 | 데이터 | 용도 |
|------|------|--------|------|
| `/target_cmd` | geometry_msgs/Twist | linear.x=거리(m), angular.z=각도(rad) | 사람 추적 중 (follow) |
| `/search_cmd` | std_msgs/String | "left" 또는 "right", "find" | 사람 소실 시 탐색 회전 방향 |

핵심 — **search_cmd는 watchdog(타임아웃 정지)이 반드시 필요**하다는 점을 AGV 엔지니어에게 강조하세요. 이게 없으면 재발견 후에도 회전이 안 멈춥니다.

## /target_cmd 인터페이스 정의 (AGV 엔지니어 전달용)

**토픽:** `/target_cmd`
**타입:** `geometry_msgs/Twist`
**흐름:** Orin `follow_node` 발행 → AGV `agv_control_node` 구독 → `/cmd_vel` 변환 발행

`/search_cmd`는 더 이상 사용하지 않습니다. `/target_cmd` 하나로 통합합니다.

---

### 핵심 — linear.z를 "모드 플래그"로 사용

AGV는 먼저 `linear.z` 값으로 모드를 판단한 뒤 동작합니다.

| linear.z | 모드 | linear.x | angular.z | AGV 동작 |
|----------|------|----------|-----------|---------|
| **0.0** | 추종 | 사람 거리(m) | 사람 각도(rad) | 거리 유지하며 추종(1m 목표), 각도만큼 회전 |
| **1.0** | 왼쪽 탐색 | 0.0 | 미사용 | 제자리 좌회전하며 탐색 |
| **2.0** | 오른쪽 탐색 | 0.0 | 미사용 | 제자리 우회전하며 탐색 |
| **3.0** | find/정지 | 0.0 | 미사용 | 즉시 정지 (3초간 계속 수신됨) |

---

### 각도 부호 규칙 (추종 모드, linear.z=0.0)
- `angular.z` 양수 = 사람이 화면 왼쪽 → 좌회전(CCW)
- `angular.z` 음수 = 사람이 화면 오른쪽 → 우회전(CW)
- 받은 부호를 그대로 cmd_vel 회전 방향에 사용 가능

---

### 동작 시나리오 (follow_node가 보내는 순서)
1. 사람 추종 중 → `linear.z=0.0` + 거리·각도 발행
2. 사람 놓침 → 마지막 본 방향으로 `linear.z=1.0`(왼쪽) 또는 `2.0`(오른쪽) 발행, AGV 제자리 회전
3. 탐색 중 사람 재발견 → `linear.z=3.0`(find) 발행, **3초 동안 계속** → AGV 정지 유지
4. 3초 후:
   - 사람 계속 보임 → `linear.z=0.0`(추종) 복귀
   - 사람 사라짐 → `linear.z=1.0/2.0`(탐색) 복귀

---

### AGV 처리 의사코드

```python
def target_callback(self, msg):
    mode = msg.linear.z
    cmd = Twist()

    if mode == 0.0:        # 추종
        dist_err = msg.linear.x - TARGET_DIST   # TARGET_DIST=1.0
        if abs(dist_err) > DEADBAND:
            cmd.linear.x = clip(dist_err * KP_LIN, -MAX_LIN, MAX_LIN)
        if abs(msg.angular.z) > ANG_DEADBAND:
            cmd.angular.z = clip(msg.angular.z * KP_ANG, -MAX_ANG, MAX_ANG)

    elif mode == 1.0:      # 왼쪽 탐색
        cmd.angular.z = SEARCH_SPEED     # 양수(좌회전)

    elif mode == 2.0:      # 오른쪽 탐색
        cmd.angular.z = -SEARCH_SPEED    # 음수(우회전)

    elif mode == 3.0:      # find - 정지
        cmd.linear.x = 0.0
        cmd.angular.z = 0.0

    self.cmd_vel_pub.publish(cmd)
```

---

### 요청 사항
1. **watchdog** — `/target_cmd`가 0.5초 이상 안 오면 자동 정지(cmd_vel=0). follow_node 종료/통신 끊김 대비.
2. **탐색 회전 속도**(`SEARCH_SPEED`)는 AGV 쪽에서 설정. 좁은 공간이면 느리게.
3. find(3.0)는 3초간 계속 발행되니, 받는 동안 정지 유지하면 됩니다.

---

이대로 전달하면 됩니다. AGV 엔지니어가 확인하면 follow_node 코딩으로 넘어가겠습니다.
